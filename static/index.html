How Yoink works

            
A short guide to every feature in plain language.


            

              
The basics

              
    
                
  1. Paste a video link into the Source field at the top. Yoink supports YouTube, Instagram, Facebook, and X (Twitter), plus most other sites yt-dlp can extract. You can also drop a link onto the window from your browser.
    2. 
                
  2. Click Scan, or press Ctrl+Enter. Thumbnails appear below, each with a small badge in the corner showing where it came from.
    3. 
                
  3. Paste another link to add more videos to the queue. Existing ones stay. Use Clear queue at the bottom to start over.
    4. 
                
  4. Click any thumbnail to toggle it. The red border means selected.
    5. 
                
  5. Choose MP4 or MP3, pick a quality, and confirm the destination folder.
    6. 
                
  6. Click Download or press Ctrl+D. Each card shows its own progress.
    7. 
              


              
Download history

              
Click the down-arrow icon at the top right (or open Settings, History) to see every video Yoink has finished. The Skip already-downloaded toggle in Settings, Downloads uses this list to prevent re-downloading the same video. You can clear the visible list, or clear the list plus the archive (which forgets what was downloaded).


              
Supported sites

              
    
                
  • YouTube: single videos, playlists, channels. Public videos work without any setup.
    • 
                
  • Instagram: reels and public posts work directly. Stories and private accounts require cookies (see Cookies from browser below).
    • 
                
  • Facebook: public videos work. Group or friends-only videos require cookies.
    • 
                
  • X (Twitter): most embedded videos work. Some posts require cookies.
    • 
                
  • Other sites: yt-dlp supports about a thousand sites. Most of them just work if you paste the link.
    • 
              


              
Format and quality

              
Use the Format toggle to switch between MP4 (video file) and MP3 (audio only).

              
When MP4 is on, the Quality control shows resolutions: 720p, 1080p, 4K, or Max. Max picks the highest available.

              
When MP3 is on, the Quality control swaps to bitrates: 128, 192, or 320 kbps. Higher numbers mean better audio at the cost of file size.

              
Defaults live in Settings on the Format tab. What you pick on the homepage is a one-time override that resets next launch.


              
Destination

              
    
                
  • Type or paste a folder path.
    • 
                
  • Click Browse to pick a folder using a native dialog.
    • 
                
  • Click Open to open the current folder in File Explorer.
    • 
              


              
Clip range

              
To download only part of a video, set a start and end time. Each field has three cells for hours, minutes, and seconds.

              
Click any cell, type two digits, and focus jumps to the next cell automatically. Typing a colon also jumps. Leave everything at 00:00:00 to download the full video.

              
If you paste a YouTube URL that contains a timestamp like ?t=163, the start time fills in for you.


              
Filename template

              
Settings, Organization tab. The template controls how files get named. Click any tag chip to insert it at your cursor. Use a slash (/) to create subfolders.

              
    
                
  • {title}: video title
    • 
                
  • {channel}: channel name
    • 
                
  • {n}: playlist position number (01, 02, and so on). Empty for single videos.
    • 
                
  • {playlist}: playlist name. Empty for single videos.
    • 
                
  • {quality}: the quality you picked, like 1080p or 192kbps
    • 
                
  • {upload_date}: when the video was uploaded
    • 
                
  • {download_date}: today
    • 
                
  • {id}: YouTube video id
    • 
                
  • {ext}: file extension (auto-added if you do not include it)
    • 
              

              
Try {n} - {title} for "01 - Title.mp4", or {channel}/{title} for one folder per channel.


              
Hide to tray

              
Click the Background button at the top right to send the window to your system tray. Downloads keep running. Click the tray icon to bring the window back. Closing the window with the X stops everything.


              
SponsorBlock

              
Settings, SponsorBlock tab. SponsorBlock is a community database of sponsor segments inside YouTube videos.

              
After scanning, Yoink fetches segment info automatically. Coloured bars show where each segment sits on the thumbnail, and chips below the title summarise them by category.

              
Three modes:

              
    
                
  • Off: segments still get previewed on cards, but nothing is changed in the file.
    • 
                
  • Mark: segments become chapters in the file. The video plays normally, you can skip them in chapter-aware players.
    • 
                
  • Remove: segments get cut out of the file entirely.
    • 
              

              
Use the checkboxes to pick which categories count. Each category has its own colour, matching the bars on the thumbnail.


              
Subtitles

              
Settings, Subtitles tab. Toggle on to download subtitles and embed them into the video file. Use the Languages field to list which languages to fetch, separated by commas (like en, nl, es). Yoink falls back to auto-generated subtitles when official ones are not available.


              
Cookies from browser

              
Settings, Authentication tab. For age-gated, members-only, or private videos, Yoink can read your browser cookies so it acts as your logged-in account. Pick which browser to use. You do not need to watch the video first, just be logged in.


              
Concurrent downloads

              
Settings, Downloads tab. By default Yoink downloads one video at a time. You can switch to 2 or 3 in parallel. Higher numbers can be faster on a fast connection, but YouTube sometimes throttles parallel requests so the gain depends on your network.


              
Open destination when done

              
Settings, Downloads tab. When all downloads finish, the destination folder pops open in File Explorer.


              
Updates

              
Settings, Updates tab. Yoink uses yt-dlp to fetch videos. YouTube changes break it from time to time, and yt-dlp updates fix that. Click Check for updates to pull the latest version. After an update, restart the app to pick it up.

Build a filename pattern using tags. Use / to create subfolders. Click any chip below to insert it at your cursor.

{n} — playlist position (01, 02, …); empty for single videos. Add your own separator: {n} - {title}

              
{playlist} — source playlist name; empty for single videos. Combine with / for a subfolder per playlist.

              
Leading separators after empty tags get trimmed automatically — so {n} - {title} still works for single videos.

              
Examples: {n} - {title} · {channel}/{title} · {playlist}/{n} - {title}
